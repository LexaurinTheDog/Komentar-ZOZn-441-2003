# Komentář k zákonu č. 441/2003 Sb., o ochranných známkách

Otevřený komentář k zákonu o ochranných známkách (ZOZn) — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; důvody zamítnutí, účinky a užívání známky, převod a licence, přihláška a námitky, zrušení a neplatnost, kolektivní a certifikační známky, mezinárodní zápisy a známka EU.

Konsolidované znění: dokument e-Sbírky `SB-2003-00441_2022-02-01`.
